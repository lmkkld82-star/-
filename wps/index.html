    قواعد مهمة

    • تُحوَّل الرواتب عبر النظام خلال 3 أيام من نهاية الشهر المستحق (القرار 729/2024).
    • النظام يقارن المبلغ المحوَّل بالراتب في عقد كل عامل. الفرق يظهر كمخالفة، فحدّث العقد عند تغيير الراتب.
    • بدون مسافات زائدة في البيانات، ومسافة واحدة فقط بين أجزاء الاسم.
    • نوع الهوية: C للبطاقة المدنية و P لجواز السفر.
    • رمز بنك العامل من القائمة، ورمز بنك مسقط BMUSOMRX.
    إعداد Excel (فقط إذا استخدمت منشئ ملفات البنك)
    1. افتح ملف Excel جديد واحفظه على جهازك (Desktop)، ولغة Excel إنجليزية، وتجنب المجلدات المشتركة.
    2. File ← Options ← Trust Center ← Trust Center Settings.
    3. Macro Settings ← Enable all macros.
    4. نزّل "محرر ملفات WPS" من صفحة رفع الملف في الخدمات المصرفية، والصق فيه بيانات نسخة Excel كقيم، ثم Generate Sif File.
