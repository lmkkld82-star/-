# رواتب فكرة التميز · WPS

تطبيق ويب لتجهيز ملفات رواتب نظام حماية الأجور (WPS) في سلطنة عمان، وإنشاء ملف الرفع (SIF) لبنك مسقط.

- الأشهر والعمال والمبالغ قابلة للتعديل، والصافي والإجمالي يُحسبان تلقائياً.
- زر لتنزيل ملف الرفع `SIF_<CR>_BMCT_<YYYYMMDD>_<seq>.xlsx` ونسخة Excel بنفس شكل منشئ ملفات البنك.
- خطوات الرفع في الخدمات المصرفية لبنك مسقط بقيم الشهر المختار، مع الروابط وأرقام الدعم.

## الخصوصية

لا توجد أي بيانات للعمال داخل هذا المستودع. البيانات تُحفظ في متصفح من يستخدم التطبيق فقط (localStorage)،
وتُفتح من ملف JSON يحتفظ به صاحب الشركة على جهازه، مع زر لحفظ نسخة احتياطية.

## التشغيل

افتح رابط GitHub Pages للمستودع، ثم من قسم «بيانات الشركة» اضغط «فتح ملف البيانات (JSON)».
