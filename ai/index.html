النموذج
على نفس الجوال (Termux): http://localhost:20128 — أو رابط https لخادمك إن كان على الإنترنت.
من لوحة OmniRoute ← API Keys. يُحفظ على هذا الجهاز فقط.
  1. ثبّت تطبيق Termux من F-Droid (نسخة متجر Play قديمة).
  2. افتح Termux وانسخ هذا الأمر (مرة واحدة فقط): 
    pkg update -y && pkg install -y nodejs-lts python build-essential git
  3. شغّل OmniRoute (كل مرة تريد استخدامه): 
    npx -y omniroute@latest
    اترك Termux مفتوحاً في الخلفية، وأوقف "تحسين البطارية" له.
  4. اضغط فتح لوحة OmniRoute في تبويب الاتصال، وأنشئ كلمة مرور للوحة.
  5. من Providers اربط مزوّداً واحداً على الأقل (مثلاً Gemini أو Groq أو OpenRouter بمفتاحهم المجاني).
  6. من API Keys أنشئ مفتاحاً وانسخه، ثم الصقه هنا في تبويب الاتصال واضغط حفظ واختبار.
على الكمبيوتر بدلاً من الجوال: npm install -g omniroute && omniroute ثم افتح هذه الصفحة من نفس الكمبيوتر.
